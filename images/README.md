# Gallery images

Drop your real project photos here to fill the **Our Work** gallery on the site.

Name them exactly:

```
images/gallery-1.jpg   → Patios & Pavers
images/gallery-2.jpg   → Lawn Care & Mowing
images/gallery-3.jpg   → Mulching & Planting
images/gallery-4.jpg   → Tree Pruning & Removal
images/gallery-5.jpg   → Concrete & Walkways
images/gallery-6.jpg   → Custom Decks
```

Tips:
- Landscape orientation, roughly **4:3**, looks best (e.g. 1200×900).
- `.jpg` keeps file size small for fast loading. (`.png` works too — if you use it,
  update the file extension in `index.html`.)
- Until a photo is added, that tile shows a clean colored placeholder with its
  label — nothing looks broken, so you can add photos whenever you have them.

To add, rename, or caption tiles, edit the `<figure class="shot">` blocks inside the
`#gallery` section of `index.html`.
